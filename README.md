# 袴カタログ（モバイル版）

シンプルなHTML/CSS/JSで作成したモバイル向け袴カタログです。ビルド不要で、`index.html` をブラウザで開くだけで動作します。

## 使い方

1. `index.html` をブラウザ（特にスマートフォン）で開く
2. 上部の色フィルターで商品を絞り込み
3. 商品カードをタップすると詳細（価格・柄・説明・問い合わせボタン）が表示されます

## 画像の追加方法

`images/` フォルダに、以下のファイル名で袴の写真を追加してください（jpgやpngなど）。

```
images/001.jpg
images/002.jpg
images/003.jpg
...
images/012.jpg
```

- 推奨サイズ：横 800px 以上、縦横比 3:4 程度（例: 900×1200px）
- 画像が未配置の商品は自動的にプレースホルダー画像（`images/placeholder.svg`）が表示されます
- 商品を追加・変更する場合は `js/data.js` を編集してください（`image` の値を対応するファイル名にする）

## 商品データの編集

`js/data.js` に商品情報の配列があります。1商品ごとに以下の項目を持ちます。

| 項目 | 内容 |
|---|---|
| name | 商品名 |
| price | 通常価格（税込・数値。未定の場合は null） |
| memberPrice | 会員30%OFF価格（税込・数値。未定の場合は null） |
| colors | 色の配列（複数指定可。フィルターのチップに使用、いずれか一致でOR検索） |
| pattern | 柄の種類 |
| image | 画像ファイルのパス（例: `images/001.jpg`） |
| tags | バッジ表示用タグ（例: "人気", "新作"） |
| description | 詳細説明文 |

商品を追加したい場合は、この配列に同じ形式でオブジェクトを追加してください。

## お問い合わせ先の設定

`js/script.js` 内の `mailto:info@example.com` の部分を、実際の問い合わせ先メールアドレスに書き換えてください。

## フォルダ構成

```
hakama-catalog/
├── index.html          # メインページ
├── css/style.css        # デザイン
├── js/data.js            # 商品データ
├── js/script.js          # 表示・検索・フィルター処理
└── images/                # 商品画像（ご自身で追加）
    └── placeholder.svg    # 画像未配置時のプレースホルダー
```
